# Paper Ingestion (step group)

This document is the index for **phase 2, step 2** of the Topic scope workflow in [README.md](../../README.md). **Paper Ingestion** groups the leaf steps that turn search candidates into durable, fulfilled, briefed, evaluated, and indexed papers.

It is a **docs-only group** in v1: there is no dedicated Streamlit page for step 2.2. After [Search external sources](2.1-search-external-sources.md), the UI continues to the first leaf substep, [Paper archiving](2.2.1-paper-archiving.md).

Phase landing: [External sources ingestion](2-external-sources-ingestion.md).

## Glossary

| Term | Meaning |
| --- | --- |
| **Paper Ingestion** | Step group 2.2: archive candidates, fulfill metadata, generate paper briefs, evaluate paper briefs, and index papers for **Papers search**. |
| **Leaf substep** | A Streamlit page under this group, or a docs-only / schema-only leaf. v1 Streamlit pages: **Search** is 2.1; under 2.2 only **Paper archiving** has a page (it also shows fulfill/brief progress). **Paper brief evaluation** (`2.2.4`) is docs-only. **Paper indexing** (`2.2.5`) is schema-only. |

# Add reference

This document is the specification for **phase 3, step 3.2** of the Topic brief generation workflow in [README.md](../../README.md). v1 is a **stub page**. Attaching References from local search results is not built yet.

Phase landing: [References selection](3-references-selection.md). List path: [Show references](3.1-show-references.md). Search capability: [Papers search](papers-search.md).

## Glossary

| Term | Meaning |
| --- | --- |
| **Add reference** | References selection step 3.2: search the local ingested paper store, then attach one or many results as **References** for the current `TopicScope`. |
| **Reference** | Durable many-to-many link from one `TopicScope` to one ingested `Paper`. See [Show references](3.1-show-references.md). |

## Scope

### In scope (current v1)

- Reserve the step name, number, and UI contract.
- Require `topic_scope_key`; load the `TopicScope` and its facets as needed for search input.
- Run [Papers search](papers-search.md) against the local ingested paper store/index for this Topic scope.
- Show each search hit as an ingested `Paper`, marked **already a Reference** for this scope or **not yet**.
- Primary/default **Add** button per paper that is not yet a Reference (mutate; [ui-style.md](../ui-style.md)).
- **Add all results** button: attach every search hit that is not already a Reference for this scope.
- Idempotent attach: unique `(topic_scope_id, paper_id)`; skip papers already referenced.
- Fail-soft: skip invalid rows without aborting the whole batch; report skipped count when useful.
- Shared References selection phase header/stepper; page_link back to **Show references**.

### Out of scope (v1)

- Owning Papers search query rules (owned by [papers-search.md](papers-search.md)).
- Building the paper index ([Paper indexing](2.2.4-paper-indexing.md)).
- Searching external sources ([Search external sources](2.1-search-external-sources.md)).
- Listing-only UI ([Show references](3.1-show-references.md)).
- Removing a Reference.
- Topic-brief drafting.

## Attach rules

| Rule | Detail |
| --- | --- |
| Identity | Attach by durable ingested `Paper` (DOI / paper id rules owned by [Paper archiving](2.2.1-paper-archiving.md)). |
| Idempotent | Creating a Reference that already exists is a no-op (or treated as success without duplicate rows). |
| Add all | Iterates current search results only; skips papers already referenced for this Topic scope. |
| Fail-soft | One bad row does not roll back successful attaches in the same batch. |

## Streamlit UI (v1)

Module: `paper_reviewer.ui.add_reference` with `render_add_reference()`. The page is registered. Attach, Papers search, and Add / Add all are **not built**. With a Topic scope key the page shows the phase header, the step name, and a not-built caption, plus a page_link to **Show references**.

| Property | Value |
| --- | --- |
| `key` | `add_reference` |
| `title` | Add reference |
| `url_path` | `add-reference` |
| `in_sidebar` | false ([ui-style.md](../ui-style.md)) |

### Page behavior

1. Require `topic_scope_key`. Missing key → empty state + page_link to **Topic intake** and **Topic scope**.
2. Show the References selection phase header; then `st.header` **Add reference**.
3. Run or refresh Papers search for this Topic scope (exact auto-run vs explicit Search button is an implementation detail; results must use Papers search).
4. For each result: show paper summary fields; badge or caption whether it is already a Reference for this scope.
5. For papers not yet referenced: **Add** button (mutate) creates the Reference.
6. **Add all results** button (mutate) attaches every not-yet-referenced hit; skips already-referenced papers.
7. Page_link to **Show references** (`show_references`) to review the current list.

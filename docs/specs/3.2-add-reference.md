# Add reference

This document is the specification for **phase 3, step 3.2** of the Topic brief generation workflow in [README.md](../../README.md).

v1 **runs Papers search, shows results, and attaches hits** with **Add** and **Add all results**.

Phase landing: [References selection](3-references-selection.md). List path: [Show references](3.1-show-references.md). Search capability: [Papers search](papers-search.md).

## Glossary

| Term | Meaning |
| --- | --- |
| **Add reference** | References selection step 3.2: search the local ingested paper store, then attach one or many results as **References** for the current `TopicScope`. |
| **Reference** | Durable many-to-many link from one `TopicScope` to one ingested `Paper`. See [Show references](3.1-show-references.md). |

## Scope

### In scope (current v1)

- Require `topic_scope_key`; load the `TopicScope` and its facets as needed for search input.
- Auto-run [Papers search](papers-search.md) against the local ingested paper store for this Topic scope (no Search button).
- Show each search hit as an ingested `Paper`, marked **already a Reference** for this scope or **not yet**.
- Secondary **Add** button per paper that is not yet a Reference (mutate; [ui-style.md](../ui-style.md)).
- Secondary **Add all results** button: attach every current search hit that is not already a Reference for this scope.
- Attach via `add_references` by DOI; skip papers already referenced for this Topic scope (no duplicate row).
- Shared References selection phase header/stepper; page_link back to **Show references**.

### Out of scope (v1)

- Owning Papers search query rules (owned by [papers-search.md](papers-search.md)).
- Building the paper index ([Paper indexing](2.2.4-paper-indexing.md)).
- Searching external sources ([Search external sources](2.1-search-external-sources.md)).
- Listing-only UI ([Show references](3.1-show-references.md)).
- Removing a Reference.
- Topic-brief drafting.

## Public API

Package path: `paper_reviewer.topic_brief_generation.add_reference`.

```text
add_references(session, topic_scope, dois) -> None
```

| Argument | Type | Role |
| --- | --- | --- |
| `session` | SQLAlchemy `Session` | Persistence. **Caller owns commit.** |
| `topic_scope` | `TopicScope` | Scope that receives the References. |
| `dois` | sequence of `str` | Public Paper identity for each attach. Empty → no-op. |

Do **not** put private `Paper.id` on this API. Do **not** return a result type.

| Rule | Behavior |
| --- | --- |
| DOI | Strip surrounding whitespace; uppercase; look up with `get_paper_by_doi`. |
| Already a Reference | Unique `(topic_scope_id, paper_id)` already exists → skip that DOI (no duplicate row, no raise). |
| Missing Paper or blank DOI | Raise `AddReferenceError`. Do not continue the rest of `dois`. |
| Other DB / session error | Raise. Do not continue. |
| Transaction | No savepoint per DOI. The caller rolls back the whole call when the function raises. |
| ORM | Use `create_reference` for new rows. Do **not** make that helper idempotent. |

## Attach rules

| Rule | Detail |
| --- | --- |
| Identity | Attach by durable ingested `Paper`. DOI / paper id rules owned by [Paper archiving](2.2.1-paper-archiving.md). |
| Idempotent | Creating a Reference that already exists is a no-op (no duplicate row). |
| Add all | Iterate current search results only; skip papers already referenced for this Topic scope. |
| Failure | One bad DOI aborts the call. Successful attaches from that call are not committed. |

## Streamlit UI (v1)

Module: `paper_reviewer.ui.add_reference` with `render_add_reference()`. The page is registered. Papers search, result display, **Add**, and **Add all results** are **built**.

| Property | Value |
| --- | --- |
| `key` | `add_reference` |
| `title` | Add reference |
| `url_path` | `add-reference` |
| `in_sidebar` | false ([ui-style.md](../ui-style.md)) |

### Page behavior

1. Require `topic_scope_key`. Missing key, non-UUID value, or no `TopicScope` row → empty state + page_link to **Topic intake** and **Topic scope**.
2. Show the References selection phase header; then `st.header` **Add reference**. Do **not** repeat the Reference-id caption (the header already shows it).
3. Auto-run Papers search for this Topic scope via `search_papers` (no Search button).
4. Load error → `Could not load Papers search for this Topic scope. Try again.`
5. Empty results:
   - No usable concepts → caption `No topic facet concepts to search. Run Topic analysis first.`
   - Concepts exist, zero hits → caption `No ingested papers match this Topic scope's concepts.`
6. When truncated (`PapersSearchResult.truncated`) → caption `Showing the first 20 matching papers.`
7. When at least one hit is not yet a Reference: secondary **Add all results** button above the hit list (`type="secondary"`). Do **not** show it when every hit is already a Reference, or when there are no hits. On click: `add_references` with the DOIs of current hits where `already_referenced` is false (the shown cap of 20, not papers beyond truncation).
8. For each hit: title as a content link to `url`; caption `authors · journal · year · DOI` (em dash when authors/journal/year are missing); then `st.badge` **Already a Reference** or **Not yet a Reference** (default badge colour only); then `st.badge` **Paper brief available** (default badge colour) or **Paper brief not available** (`color="orange"` — Streamlit warning/caution colour; from `paper_brief_available`).
9. For each hit that is not yet a Reference: secondary **Add** button (`type="secondary"`; widget key from the DOI). Do **not** show **Add** on already-referenced hits. Do **not** gate Add on Paper brief availability.
10. On **Add** or **Add all results**: success → `st.rerun()` so search runs again and badges update. Failure → `Could not add References for this Topic scope. Try again.` Do **not** `st.switch_page`.
11. Page_link to **Show references** (`show_references`) to review the current list.

Entry from Show references: [3.1-show-references.md](3.1-show-references.md).

# Paper indexing

This document is the specification for **phase 2, step 2.2.4** of the Topic brief generation workflow in [README.md](../../README.md). v1 is a **shell**. Indexing an ingested paper for local **Paper search** is not built yet.

**Parent group:** [Paper Ingestion](2.2-external-sources-ingestion.md). Phase landing: [External sources ingestion](2-external-sources-ingestion.md).

## Glossary

| Term | Meaning |
| --- | --- |
| **Paper indexing** | Planned leaf step that indexes an ingested paper so [Paper search](3-paper-search.md) can find it in the local database. |

## Scope

### In scope (current v1)

- Reserve the step name and number in the workflow docs.
- Keep this step **out** of the External sources ingestion UI stepper until a page exists.

### Out of scope (v1)

- Building or updating a search index.
- A Streamlit page, domain package, or Prefect flow for indexing.
- Local Paper search query behavior ([3-paper-search.md](3-paper-search.md)).

## Streamlit UI (v1)

Not registered. Do not add a page key or stepper entry until this step is implemented.

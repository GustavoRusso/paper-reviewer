# Paper indexing

This document is the specification for **phase 2, step 2.2.4** of the Topic brief generation workflow in [README.md](../../README.md). v1 is a **shell**. Indexing an ingested paper for local **Papers search** is not built yet.

**Parent group:** [Paper Ingestion](2.2-paper-ingestion.md). Phase landing: [External sources ingestion](2-external-sources-ingestion.md).

## Glossary

| Term | Meaning |
| --- | --- |
| **Paper indexing** | Planned leaf step that indexes an ingested paper so [Papers search](papers-search.md) can find it in the local database. |

## Scope

### In scope (current v1)

- Reserve the step name and number in the workflow docs.
- Keep this step **out** of the External sources ingestion UI stepper until a page exists.

### Out of scope (v1)

- Building or updating a search index.
- A Streamlit page, domain package, or Prefect flow for indexing.
- Papers search query behavior ([papers-search.md](papers-search.md)).
- Attaching References ([Add reference](3.2-add-reference.md)).

## Streamlit UI (v1)

Not registered. Do not add a page key or stepper entry until this step is implemented.
